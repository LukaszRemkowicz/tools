# tools

Personal utilities.

- [`pixinsight/`](pixinsight/) – PixInsight helpers.
- [`MacOS/pathbar/`](MacOS/pathbar/) – always-visible path bar for macOS Open/Save dialogs.
- [`seestar/`](seestar/) – download Seestar photos through the Seestar app's remote connection, with resume.
- [`seestar/seestar_relay.py`](seestar/) – make a remote Seestar appear as a LAN device to the Seestar phone app.
- [`seestar/seestar_upload.py`](seestar/) – upload files (e.g. a stack for GoTo from the album) back to the Seestar.
